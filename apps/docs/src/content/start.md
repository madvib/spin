Spin brings your design tokens, HTML element styles, layout utilities, and interactive UI components under one roof — so your team isn't stitching together a utility framework, a headless widget library, and a hand-rolled theme file that drift apart over time.

## What's inside

- **Visual Theme Studio.** Launch Studio alongside your app to pick a starting design language, shape your colors, typography, spacing, and dark mode visually against real components, and save clean theme files to your repo.
- **Finished HTML elements.** Native tags like buttons, inputs, tables, dialogs, and headings — plus lightweight surfaces like cards, badges, and alerts — look complete out of the box without twenty utility classes per element.
- **Tailwind-familiar layout utilities.** Arrange screens with flexbox, grid, spacing, surface, and radius classes backed directly by your theme scale. Typos and off-palette colors are caught at build time instead of failing silently.
- **Portable interactive components.** Copy accessible statechart templates for selects, comboboxes, menus, tabs, date pickers, and floating panels into your project and use them in React, Solid, Vue, Svelte, or plain HTML.
- **Static guardrails & MCP server.** Built-in lint rules catch unreadable contrast pairs and conflicting styles in your editor and CI, while the included MCP server gives coding agents live access to your theme and component library.

> **Public Alpha (`0.2.0-alpha.2`)** — Spin's theme engine, Studio, HTML primitives, layout utilities, and 40 statechart components are working today under the MIT license. Expect occasional refinements to token names and compiler options on the road to 1.0.
