# Spin your own web.

Spin is a verification layer plus primitives for agent-authored UI. You write
your product's visual decisions down once, as design tokens in one JSON
document. The build turns those tokens into utilities and finished HTML
elements. Oracles check the result mechanically — in the source, in the browser,
and before the agent writes a word.
