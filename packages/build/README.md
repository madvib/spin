# @spinjs/build

The build stages: the components stage, the strict gate over worn classes,
the content scan, and the cross-theme report. The plugin composes these;
the LSP reads the gate's suggestion half.

```ts
import { checkStrictClasses, scanContent } from "@spinjs/build";
```

## Subpaths

- `@spinjs/build` — stages, gates, and the build's own vocabulary.
